Recent jobs (all users, read-only)

Admins see job metadata only — no commands, code or logs, and cannot stop a single job. To stop a user's work, suspend the user (Users → Open).

Compute nodes

Capacity, used and free are what each node reports on /v1/info; "jobs here" are the jobs this server has running on it. A draining node gets no new jobs and its running jobs finish normally. Nodes are configured in server/.env (DOCKERSERVER_NODES). An AWS Lambda node runs one job per invocation; it shows its concurrency slots instead of CPU/memory and gets jobs only when no Docker node has room.

Usage report

Site containers per user

Each static site runs in its own small nginx container (32 MB, 0.25 CPU) that starts on the first visit and is stopped after an idle hour. Admins see metadata and usage only; deleting a user removes their sites and containers.
